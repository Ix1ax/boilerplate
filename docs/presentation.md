## Архитектура

```
Браузер → Nginx → gateway (вход, роли, лимиты, аудит)
                     ├─ tasks ─┐            Postgres на каждый сервис
                     ├─ files ─┤ RabbitMQ   S3 для файлов
                     ├─ notifications       Redis: сессии и лимиты
                     ├─ audit               Keycloak: пользователи
                     └─ llm → Ollama (Qwen, локально)
```

Независимые сервисы и базы · события через outbox · один запуск: `make demo`

---

## ИИ с человеком в контуре

- **Правила** ставят флаги детерминированно — модель их не отменит
- **Qwen** (локально, без платных API) даёт совет в проверяемом JSON
- **Человек** принимает решение; без модели всё работает по правилам

---

## Надёжность и безопасность

- Keycloak OIDC + PKCE, HttpOnly-сессии, CSRF, роли проверяются в Go
- Владелец записи — в SQL, лимиты запросов, защита от двойной отправки
- Журнал действий, сквозной `request_id`, метрики Prometheus
- Только свободное ПО: Postgres, Redis 7.2, RabbitMQ, Keycloak, Qwen2.5 (Apache 2.0)
