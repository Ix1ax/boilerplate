# Проверка шаблона

Проверено 16 октября 2026 года.

| Проверка           | Результат                                                                                                                        |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `make check`       | Пройдено: Go-тесты с `-race`, Go vet, сборка Go, TypeScript, ESLint, форматирование, 7 тестов Vitest и production-сборка Next.js |
| `make integration` | Пройдено: миграции, PostgreSQL, пагинация и изоляция записей разных владельцев                                                   |
| Docker Compose     | Весь стек собран и запущен; API, фронтенд и зависимости готовы, контейнер миграций завершился успешно                            |
| Первый запуск      | Повторён в новых томах: миграции, подстановка паролей из env при импорте realm и русская форма входа работают                    |
| `make smoke`       | Пройдено на окончательных образах: JWT, роли, валидация, задачи, приватность файлов, S3 и CSRF                                   |
| Браузер            | Проверены вход через Keycloak, создание задачи, завершение, сохранение после перезагрузки и выход                                |
| Экспорт            | Секреты, локальные данные, зависимости и сборки не попадают в новую копию                                                        |
| Чистая копия       | `npm ci` и `npm run typecheck` прошли без зависимости от исходной папки и без предварительной сборки                             |
| Повторный `setup`  | Существующие пароли сохраняются                                                                                                  |

На компьютере использовались Go 1.26.2 и Node.js 25.9.0. Docker-сборка фронтенда выполнена на Node.js 24; для команды рекомендуется версия 24 из `.nvmrc`. Vitest не заявляет поддержку Node.js 25, хотя локальные тесты на этой версии прошли.

В `npm audit` осталось пять связанных предупреждений в инструментах разработки из-за одной цепочки с `braces`. Предупреждений в зависимостях работающего приложения после замены вложенного PostCSS не осталось. Подробности и ссылки — в [development.md](development.md#предупреждение-в-зависимостях-линтера).

Перед новым хакатоном повторите проверки: состояние пакетов и окружения со временем меняется. Автоматическая проверка API не заменяет ручной проход вашего продуктового сценария.
