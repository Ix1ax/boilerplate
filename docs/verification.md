# Проверка шаблона

Проверено 17 октября 2026 года после согласования нового Vite-фронтенда с Go API и инфраструктурой.

| Проверка           | Результат                                                                                                                                                                                                 |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `make check`       | Пройдено: Go-тесты с race, vet и сборка, TypeScript всех workspaces, ESLint, Prettier, 3 теста Vitest и production-сборка Vite                                                                            |
| `make integration` | Пройдено: PostgreSQL, миграции, владельцы и пагинация задач и файлов; Redis, одноразовый OIDC state, PKCE, cookie, параллельный refresh, CSRF и выход                                                     |
| Docker             | Приложения собраны; первый запуск в отдельных новых томах прошёл, API, web и зависимости готовы, миграции завершились успешно                                                                             |
| `make smoke`       | Пройдено: SPA-маршруты, OIDC/PKCE, JWT, роли, валидация, CRUD задач, список и приватность файлов, S3 и CSRF                                                                                               |
| Браузер            | Проверены главная страница, перенаправление гостя, настоящий вход через Keycloak, создание и завершение задачи, загрузка файла, сохранение данных после перезагрузки и выход с запретом закрытой страницы |
| Чистый экспорт     | Отдельный каталог без Git, секретов и сборок; новое имя проекта; `npm ci`, проверка типов и сборка прошли без старых node_modules                                                                         |
| Повторный setup    | Пароли сохраняются, отсутствующие настройки дополняются, пользовательские значения не перезаписываются                                                                                                    |
| `npm audit`        | После удаления неиспользуемого CLI shadcn — 0 известных уязвимостей на момент проверки                                                                                                                    |

Локальные проверки выполнены на Go 1.26.2 и Node.js 25.9.0; Docker-сборка фронтенда — на рекомендованном Node.js 24. Для разработки и CI используйте Node.js 24 из `.nvmrc`: Vitest не заявляет поддержку Node.js 25.

На компьютере найдены старые тома Compose-проекта `hackathon-starter` с другими паролями. Их содержимое сохранено; текущая локальная `.env` использует отдельное имя `boilerplate`. Для новой копии задайте своё имя проекта и свободные порты. Браузерная проверка использовала существующего демопользователя; созданные ею задачу и файл удалили после проверки.

Это проверка локального шаблона, не аудит готового production-проекта. Подготовка внешнего окружения описана в [deployment.md](deployment.md). Повторяйте проверки после смены контрактов, инфраструктуры или зависимостей.
