# Правила работы с шаблоном

Это самостоятельная монорепа: Go API в `apps/api`, Next.js в `apps/web`, общие UI и контракты в `packages`.

- Пишите документацию, поясняющие комментарии и сообщения интерфейса по-русски. Комментарии нужны для причин и ограничений, а не для пересказа кода.
- Не переносите сюда предметную область прошлого хакатона, реальные адреса и секреты. Используйте `.env.example`; локальные значения создаёт `make setup`.
- Во фронтенде соблюдайте направление зависимостей `app → screens → features → entities → shared`. `packages/ui` не зависит от приложения.
- Авторизацию и проверку доступа выполняйте в Go. Для записей пользователя проверяйте владельца в SQL; клиентские ограничения служат только интерфейсу.
- API, OpenAPI, TypeScript-типы и входные схемы меняйте согласованно. Миграции добавляйте отдельными файлами.
- Перед завершением изменения запускайте подходящие проверки. Общая команда — `make check`; инфраструктура проверяется через `make integration` и `make smoke`.
- Не публикуйте, не разворачивайте и не отправляйте изменения в remote без прямого поручения пользователя.
