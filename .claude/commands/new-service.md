---
description: Добавить новый Go-микросервис по образцу apps/tasks
argument-hint: <имя-сервиса> <краткое описание домена>
---

Создай сервис `$ARGUMENTS` строго по рецепту «Как добавить сервис» из AGENTS.md. Образец — `apps/tasks`. Не меняй чужие сервисы, кроме подключения в gateway. После шагов выполни `go build ./... && go test ./...` в новом модуле, затем `make check`. В конце кратко перечисли изменённые файлы.
