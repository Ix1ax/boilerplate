## Design Context

### Пользователи и задачи

По `docs/case.md`: люди, которые ищут компанию для спорта, представители клубов
и модераторы. Основные задачи — найти встречу, записаться, организовать свою,
рассмотреть заявки и получить понятное решение. Адаптивный веб обязателен.

### Направление и тон

Пользователь потребовал консистентности новых страниц с существующим интерфейсом.
Эталон — `/events`, `/my`, карточка встречи и готовые shared-компоненты.
Сохранять текущие шрифты, палитру, геометрию и русский язык. Новое визуальное
направление для отдельных страниц не вводить.

### Реализация

React, React Router, Tailwind, Base UI через `shared/ui`, RHF и общие Zod-схемы.
HeroBand для заголовков разделов; контейнер 1280 px, горизонтальные отступы
px-4 / sm:px-8; карточки rounded-3xl bg-card. Использовать Form, Select,
Checkbox, Notice, Badge и Button из shared. Не дублировать main из RootLayout.
Состояния ожидания, ошибки, пустого списка и успеха входят в готовый сценарий.
